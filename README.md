# Abortion Is Too Hard to Find From the Gorge

A memo from [Gorge Access](https://gorgeaccess.org) to Columbia River Gorge health care providers and the agencies that fund them: there is no abortion provider in the Gorge, finding that out is unacceptably hard because only the organizations against abortion use the word online, and the fixes are free. Built from a 42-search Google audit run October 28, 2026, the centers' own pages, and the two states' Rural Health Transformation award records.

Read it at https://kate-rose.github.io/gorge-repro-access/ or download the [PDF](Abortion-Is-Too-Hard-to-Find-From-the-Gorge_Gorge-Access-memo.pdf).
